# 15. Текст с разметкой — tiptap

Дата: 2026-10-08
Статус: принято. Отменяет «WYSIWYG не тащим» из FIELD-AUDIT, F1.

## Контекст

MULTI_LINE в ucode — HTML: старая админка пишет его ReactQuill'ом,
и так он лежит в данных (описания `hr_vacancies` — `<h3>…</h3><ol>…`).
До сих пор мы показывали его без тегов (`plainText`), а правили сырым
текстом — правка открывала разметку.

Форма вакансии (прототип `vacancy.html`, «Описание») и «База знаний»
(`knowledge.html`: «/»-команды, задачи, переключатели, выноски,
таблицы) требуют редактора с форматированием. Второй — блочный,
как Notion; своё поле на `contentEditable` + `execCommand` его не потянет.

## Решение

tiptap 3 (`@tiptap/react`, `starter-kit`, `extensions`, `extension-image`; ядро —
ProseMirror). Без своих стилей: оформление наше, токенами.
Обёртка одна — `shared/ui/rich-text.tsx`; значение — HTML строкой,
пустой документ — пустая строка.

Показ HTML из базы — тем же редактором в режиме чтения, а не
`innerHTML`: схема выбрасывает всё, чего не знает, включая скрипты.

Картинка грузится в хранилище файлов той же ручкой, что у полей PHOTO
(`useUploadFiles`), в HTML ложится её адрес. Загрузчик передаёт
вызывающий (`onUpload`): `shared` ручек не знает.

Грузится лениво (`lazy`) там, где нужен: в первую загрузку не попадает.

## Цена

- Отдельный чанк ~400 КБ (126 КБ gzip) — грузится только там, где есть редактор.
- Неизвестная схеме разметка из старой админки (стили Quill, классы)
  при первом сохранении из редактора теряется. Текст и структура
  (абзацы, заголовки, списки, жирный) остаются.
- Версии пакетов tiptap — строго одинаковые (peer-зависимости
  `@tiptap/pm` и `@tiptap/core` на точную версию), поэтому закреплены
  без `^` и поднимаются вместе.

## Отвергнуто

- Своё поле на `contentEditable`: «База знаний» его перерастает,
  а `execCommand` устарел и пишет разный HTML в разных браузерах.
- BlockNote: Notion-подобный из коробки, но тянет Mantine и свой вид —
  против дизайн-системы (ADR 0011).
