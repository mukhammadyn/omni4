# 11. Дизайн-система прототипа вместо new-ucode

Дата: 2026-09-30
Статус: принято

## Контекст

Код пришёл из new-ucode вместе с его дизайн-системой: бренд `#45aeff`,
свои ступени, плотность, компоненты. Дизайн omni4 — прототип
`omni4_core/crm/` в стиле Notion: акцент `#2383e2`, системный шрифт,
свои таблицы, доски, карточки и сайдбар с переключателем модулей.

## Решение

**Экраны ERP строятся на наших view, но всё рисуется заново по
прототипу** — не только view, а каждый компонент: сайдбар, drawer,
поповеры, формы, настройки, вход.

Типы view, которые есть в прототипе и нет у нас, добавляются. Бэкенд
тип view не проверяет ([ADR-0006](0006-chart-view-without-backend.md)),
поэтому каждый новый тип — чисто фронтовая работа.

Порядок: сначала токены в `app/styles.css` (одна правка перекрашивает
всё, что уже на токенах), потом компоненты `shared/ui`, потом экраны.

## Цена

- **Расхождение с new-ucode растёт с каждым компонентом.** Исправление
  там переносится сюда руками, и чем дальше, тем дороже. Логика
  (`api/`, `model/`) остаётся общей по устройству — переносится легче,
  чем `ui/`.
- **[DESIGN.md](../DESIGN.md) переписывается** по мере перехода: пока
  он описывает то, что в `styles.css`, а не прототип.
- **Контрасты проверяются заново.** У прототипа токены под светлую
  и тёмную тему свои; правило «ни одного цвета мимо токена» остаётся.
