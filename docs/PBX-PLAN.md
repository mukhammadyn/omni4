# PBX — план (2026-10-30)

Телефония CRM через onlinePBX: интеграция, запись, исходящие и входящие
звонки, всё, что есть в new-crm (`new-crm/professio_app_69f844`).
Бэкенд — общая функция `professional-crm-pbx-integration-call`
(`ucode/pbx-fn`).

## Что уже есть (PR #59)

- Карточка onlinePBX в «Интеграциях»: настройки, операторы, добавочные.
  Таблицы `pbx_settings`, `pbx_operators`, `pbx_calls`.
- Verto-транспорт `src/features/pbx/lib/verto` — умеет answer, hold,
  DTMF, transfer; в UI использован только mute.
- `CallButton` на карточках — сессия живёт внутри кнопки, входящий
  принять негде.
- `CallLog` и `useCallRecording` написаны, пункта меню журнала нет.
- Живьём ничего не проверено: нет аккаунта onlinePBX.

## Что умеет функция

| Методы | Для кого |
|---|---|
| `pbx_make_call`, `pbx_get_webrtc_credentials`, `pbx_log_call`, `pbx_get_recording`, `pbx_save_stereo_recording`, `pbx_save_transcript`, `pbx_list_untranscribed`, `pbx_debug` | любой проект |
| `crm_*` (история, пропущенные, передача сделки, сверка), поллер входящих (Redis, `pbx_sync_incoming`), входящий → сделка | только ARMADA: project-id зашиты в `business_invocation.go:40` |

## Шаги

### 1. Глобальный софтфон — основа

- [x] Verto-сессия из `CallButton` — в провайдер на уровне `_authed`:
  один логин на вкладку, переподключение
  (референс — `SoftphoneContext.tsx`).
- [ ] Индикатор «в сети / не в сети» у оператора.
- [x] Плавающая панель вместо попапа: номер, таймер, mute, hold.
- [x] `CallButton` только вызывает `softphone.call(phone)`.

### 2. Входящие звонки

- [x] Состояние `incoming`: рингтон, «Принять» / «Отклонить», вторая
  линия (`waitingNumber`).
- [x] Имя контакта / компании по номеру в панели (последние 9 цифр).
- [ ] Ссылка на карточку и поиск сделки по номеру.
- [x] Принятые входящие пишутся в `pbx_calls` с `direction: incoming`.
  Непринятые не пишутся — их могли взять на трубке или в другой
  вкладке; пропущенные — из истории onlinePBX (шаг 11).

### 3. Во время разговора

- [ ] Клавиатура DTMF.
- [ ] Перевод на номер / добавочный. Транспорт готов, нужен только UI.

### 4. Запись звонков

- [x] Запись АТС: после завершения опрашивать `pbx_get_recording`,
